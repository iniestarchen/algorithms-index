# OpenQC Algorithm Index

Central catalog for all quantum algorithm repos in the OpenQC ecosystem.

## How It Works

- **INDEX.json** — auto-generated every 6h by scanning all `algo-*` repos
- **TAXONOMY.json** — industry + technique classification labels
- **schema.json** — JSON schema for algorithm.json files
- **SUBMISSIONS.json** — community repo submissions (submit a PR to add yours)

## Browse Algorithms

Visit [openqc.io/algorithms](https://openqc.io/algorithms) to browse, filter, and run algorithms.
